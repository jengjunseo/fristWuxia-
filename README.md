# 강호 첫걸음 · 베타 완성본

한국어 선택형 무협 RPG. 8개 장소, 57개 사건, 첫 승부부터 천하제일인 엔딩까지 이어지는 여정입니다.

## 실행

Node.js 24 이상에서 `npm start`로 실행합니다. 터미널에 표시된 주소를 브라우저로 여세요. 별도 런타임 패키지는 필요하지 않습니다.

- `npm test`: 사건 분기, 전체 여정, 전투와 저장 회귀 검증
- `npm run build`: 배포용 정적 파일을 `dist/`에 생성
- Vercel: `vercel.json`의 빌드와 출력 디렉터리 설정 사용

## 이번 완성본

본문과 선택지 글씨 확대, PC/세로 화면별 재배치, 선택 결과 장면과 다음 목표, 전투 행동과 보상 개선, 저장 검증과 기존 v1 호환, 전투 중 이동·무료 회복 차단, 키보드·모달 포커스, 음악 전환을 정리했습니다.

진행은 브라우저에 자동 저장됩니다. 메뉴 → 저장 관리에서 JSON 백업과 가져오기를 지원합니다. 다운로드를 제한하는 브라우저는 내보내기 창의 저장 내용을 직접 복사할 수 있습니다. 새 여정은 해당 브라우저의 자동 저장을 덮어씁니다.

검수 결과는 [QA_BETA.md](QA_BETA.md), 초기 문제와 계획은 [BETA_AUDIT.md](BETA_AUDIT.md), 음악 출처는 [CREDITS.md](CREDITS.md)를 참고하세요. 기존 QA·인수인계 문서는 이전 기준본의 기록입니다.
