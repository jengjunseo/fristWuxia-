# 강호 첫걸음 · 2.0

야근을 마친 평범한 회사원이 횡단보도에서 트럭에 치이고 강호에서 깨어납니다. 노인 만복과의 만남 이후 이름을 정하고, 객잔의 첫 끼니부터 양곡 사건·수련·비무를 거쳐 결말까지 진행하는 한국어 무협 비주얼 노벨 RPG입니다. 8개 장소와 57개 사건을 담고 있습니다.

## 플레이

Node.js 24 이상에서 `npm start`를 실행하고 표시된 주소를 브라우저로 여세요. Windows에서는 `실행하기.ps1`도 사용할 수 있습니다. 별도 npm 의존성이나 계정, 외부 서비스가 필요하지 않습니다. HTML을 파일 탐색기에서 직접 여는 대신 로컬 서버를 사용합니다.

타이틀의 **처음부터**를 누르면 현대 사무실에서 시작합니다. 전생 후 노인이 **“공의 이름은 무엇이요?”**라고 물으면 이름을 입력합니다. 도입부의 질문도 자동 저장됩니다. **이야기 계속**은 다음 핵심 사건으로 안내하고, **이곳의 다른 이야기**와 지도는 주변 사건을 열어 줍니다. 선택지 도움말은 설정에서 감출 수 있습니다.

- 대화: 다음 버튼 또는 Enter / Space. 출력 중 한 번 누르면 문장을 완성하고, 다시 누르면 다음 대사로 넘어갑니다.
- 전투: 행동 버튼 또는 숫자 1–6. 방어는 내공을 3 회복하고, 회피는 내공 2를 써 반격 기회를 만듭니다. 기술은 내공 8을 소비합니다.
- 무공: 검식은 강한 일격, 권법은 공격과 방어, 발놀림은 공격과 회피입니다. 여러 무공을 배웠다면 전투에서 선택할 수 있습니다.
- 메뉴: 상단 메뉴 아이콘 또는 하단 지도·가방·수첩·인물·저장. Esc로 닫습니다.

패배해도 여정은 끝나지 않습니다. 치료 후 재도전하거나 도움을 받을 수 있습니다. 보스전 도움은 받는 피해를 줄이며 마지막 승부는 직접 치릅니다.

## 저장과 설정

진행은 이 브라우저에 자동 저장됩니다. 저장 관리에는 독립된 수동 슬롯 3개, 직전 자동 저장 복구, JSON 백업과 가져오기가 있습니다. 불러오기는 이름·장소·날짜를 먼저 보여 줍니다. 새 여정 전에 이전 여정을 출발 기록으로 보관하며, 보관 실패 시 새 게임을 강행하지 않습니다. 기존 v1 저장 파일도 읽습니다.

동일한 여정을 여러 탭에서 열면 먼저 진행한 탭의 기록을 보호하기 위해 다른 탭의 자동 저장이 멈춥니다. 최신 기록으로 이어 하거나 현재 탭의 기록을 백업할 수 있습니다. 브라우저 데이터 삭제 및 시크릿 모드 종료에는 저장이 사라질 수 있으므로 중요한 여정은 파일로 백업하세요. 다운로드가 막히면 저장 내용을 직접 복사할 수 있습니다.

설정은 새 여정에도 유지됩니다. 대사 속도, 큰 글씨, 움직임 줄이기, 전체·음악·효과음 음량을 조절할 수 있습니다. 메뉴를 열거나 탭을 벗어나면 전투 처리가 잠시 멈춥니다.

## 개발과 배포

```text
npm start        # 소스 실행, 기본 포트 4173
npm test         # 사건·전투·저장·전체 분기 + 실제 배포 파일 검증
npm run build    # 자체 완결된 정적 파일을 dist/에 생성
```

PowerShell에서 `$env:SERVE_DIST='1'; npm start`로 배포본을 실행할 수 있습니다. 포트가 사용 중이면 `$env:PORT='4180'`처럼 변경합니다. 정적 호스팅에는 `dist/` 내용 전체를 올리세요. Vercel 설정도 포함되어 있습니다. 글꼴·그림·음악·라이선스를 배포본에 함께 넣으므로 실행 중 외부 CDN이 필요하지 않습니다.

`game.js`는 진행과 화면, `events.js`는 사건·아이템 데이터, `prologue.js`는 현대 도입부와 전생, `narrative.js`는 핵심 대화·결말 편지, `music.js`는 상황별 10곡, `icons.js`는 무협 SVG 아이콘, `vn.css`는 새 UI를 담당합니다. `save-state.js`는 저장 검증, `storage.js`는 저장 기록 관리, `resources.js`와 `boot.js`는 이미지 준비와 시작 처리를 담당합니다. 제작용 미리보기는 `?qa`에서만 노출됩니다.
