# 강호 첫걸음 · 2.2

야근을 마친 회사원이 트럭에 치인 뒤 강호에서 눈을 뜹니다. 집으로 연락할 수도, 돈과 길을 알아볼 수도 없는 주인공이 만복·류 의원·소연·도강·청허의 도움을 받으며 21일 동안 생활과 첫 수련에 익숙해집니다. 첫 호송을 마치고 객잔에 돌아오는 한국어 무협 비주얼 노벨입니다.

## 플레이

Node.js 24 이상에서 `npm start`를 실행한 뒤 `http://127.0.0.1:4190/`를 여세요. Windows에서는 `실행하기.ps1`을 사용할 수 있습니다. 별도 npm 의존성이나 계정은 필요하지 않습니다. HTML을 파일 탐색기에서 직접 열지 않고 로컬 서버로 실행합니다.

**처음부터**를 누르면 현대 사무실에서 시작합니다. 전생 이후 노인의 **“공의 이름은 무엇이요?”**라는 질문에서 이름을 입력합니다. 현대 도입부 17개 대사 뒤에는 25개 장면, 202개 대사가 순서대로 이어집니다. 주변 탐색·사건 목록·서사 선택·보상 선택은 새 진행에 없습니다.

- 대사: 대사창, 다음 버튼 또는 Enter / Space. 출력 중 누르면 문장이 완성되고 다음에 누르면 이야기가 진행됩니다.
- 일상: 22개 장면마다 미니게임이 대사 중간에 등장합니다. 타이밍·짝맞추기·동전 계산·동작 기억·수량 확인·물건 정리·길 찾기를 완료하면 같은 장면의 대사가 이어집니다. 잘못해도 앞선 성공은 유지됩니다. 타이밍에는 느린 수동 조작, 기억 게임에는 다시 보기 기능이 있습니다.
- 전투: 행동 버튼 또는 숫자 1–6. 방어는 피해를 줄이고 내공 3을 회복합니다. 회피는 내공 2를 사용합니다. 기초 검식은 반복 수련 뒤에 익힙니다.
- 첫 위기: 도강이 올 때까지 세 공방 버티기. 이후 소연과 세 공방 연습, 동료와 함께 짐꾼들의 퇴로 지키기로 이어집니다.
- 도움 요청: 싸움에서 물러나 동료의 도움을 받고 다음 장면으로 이어갑니다. 실패 후 재도전 반복을 강제하지 않습니다.
- 메뉴: 상단 메뉴 아이콘. 가방·인물·여정 기록·저장·설정이 있습니다. Esc로 닫습니다.

전투는 위에 인물·체력·상대 예고, 아래에 최신 공방 결과와 행동 버튼을 표시합니다. 삽화는 장면당 한 번만 보여 줍니다. 전투 배경에는 인물이 없고, 투명 전신 에셋을 별도로 올립니다.

## 저장

대사 위치, 진행 중인 전투, 미니게임의 카드·물건·확인 표시·경로·성공 횟수도 자동 저장합니다. 독립 수동 슬롯 3개, 이전 기록 복구, JSON 백업과 가져오기를 제공합니다. 새 게임 전에는 기존 여정을 출발 기록에 보관합니다.

기존 저장 파일은 읽을 수 있습니다. 이전 자유 탐색 진행은 해당하는 선형 장면에 연결하고, 이름·물품·장비·돈을 유지합니다. 새 도입부 전체를 보려면 **처음부터**로 시작하세요. 같은 여정을 여러 창에서 열면 기록 충돌을 감지해 다른 창의 진행을 덮어쓰지 않습니다.

설정에서 대사 속도·큰 글씨·움직임 줄이기·음량을 조절합니다. 메뉴를 열거나 탭을 벗어나면 전투 처리가 멈춥니다.

## 개발과 배포

```text
npm start        # 기본 포트 4190
npm test         # 새 선형 진행·전투·저장·이전 저장 호환·배포 파일 검증
npm run build    # 정적 배포본 dist/
```

포트 변경은 PowerShell에서 `$env:PORT='4192'`처럼 지정합니다. 정적 호스팅에는 `dist/`의 전체 내용을 올리세요. 그림·폰트·음악·라이선스가 포함돼 외부 CDN 없이 실행합니다.

`journey.js`는 현재 선형 시나리오와 장면별 변화, `prologue.js`는 현대 도입부, `game.js`는 화면과 진행, `vn.css`는 UI, `save-state.js`와 `storage.js`는 저장을 담당합니다. `minigames.js`는 활동별 규칙·저장 검증·화면을, `minigame-art.js`는 직접 제작한 SVG 소품과 작업대 삽화를 담당합니다. `events.js`와 이전 서사 코드는 구 저장 데이터 및 개발용 검증을 위해 남겨 두었으며 새 플레이에서 사건 선택 화면으로 사용하지 않습니다.
